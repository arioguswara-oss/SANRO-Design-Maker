# V1 scope and architecture
Owner: Rio. Free to design, pay to print. Guest buyer first.
Core: transparent canvas, image upload, text, shapes, transform, pinch zoom, layers, duplicate/delete, undo/redo, outline/shadow/alignment, free background removal, IndexedDB draft recovery.
Assets: official Openverse/Pixabay APIs subject to verified commercial merchandise rights, source/license/attribution metadata; curated editable vintage, streetwear, adventure, cartoon, floral and typography templates. No arbitrary scraping.
Fonts: locally hosted licensed Google Fonts only; lazy load, production parity.
Account: WordPress/WooCommerce identity; guest temporary drafts, login/register on permanent save, safe draft claim, My Designs CRUD/duplicate/share/revoke.
Bridge: unique design ID, short-lived scoped transfer token, server validation, private references, Studio product/color/size/side then WooCommerce cart then checkout. Verify actual Studio contract read-only; no Studio changes.
Rendering: private server-side HD master, no public HD download; optional low-res watermarked preview. Screenshot prevention is not guaranteed.
Admin: top-level menu, dashboard, assets/templates/fonts/providers/watermark/storage/quota/bridge/diagnostics.
Architecture proposal: PHP modular services, REST controllers, pinned Fabric.js, JS editor state, IndexedDB, WP identity, private storage and server rendering. Validate hosting/PHP/WP compatibility and dependencies before choosing versions. Separate editor, asset, account, bridge, rendering and admin modules. No secrets in repo. Enforce authorization, guest session isolation, rate limits, upload MIME/size checks, reject unsafe SVG, SSRF protection, quotas, lifecycle/GC, XSS and IDOR prevention.
Acceptance: staging guest design-to-cart-to-checkout, login draft preservation, permanent reopen/edit, mobile/desktop, admin, license/security/performance and private master verification. No staging/merge/production without separate authorization. AI generation, premium fonts and marketplace excluded.
